# refs/ について

`refs/` は Capacitor + React + TypeScript + Vite 構成を前提にした参照実装コードとディレクトリ骨格である。

## 別スタックの場合

プロジェクトが別のスタックを採用する場合、このディレクトリごと削除してよい。`craft/` の材料はスタックに依存しないため、`refs/` が無くても運用できる。

## 構造のみを提供する

`refs/screens/` 配下のコードは、色・書体・余白をすべて `var(--token)` 経由で参照し、`docs/04-design/tokens.css` の値を直接コピーしない。トークンはプレースホルダのまま維持されているため、見た目としてはコピーできず、構造としてのみコピーできる。これは制約ではなく設計意図である。

## ディレクトリ

- `screens/<name>/` — `craft/situations/` の各項目が実例として参照する構造見本。1画面1ディレクトリ
- `src/` — 参照実装を動かすための最小限のアプリシェル（画面一覧・切替のみ）

## 実行方法

```
cd refs
npm install
npm run dev
```
