# HOW_TO_USE.md

`craft/` の材料は次の順序で使う。順序が本質なので崩さないこと。

1. 作業前: `INDEX.md` の状況名一覧から該当項目を探し、IDを宣言する（0件でよい）
2. 作る
3. 作った直後に1回だけ、引いた項目に照らして自己修正する
4. 修正内容を `docs/04-design/UI_JUDGMENTS.md` に記録する

## 注意

- 作る前だけの参照では材料が抽象のまま消える。作った後だけでは自分の出力を擁護する。**両方必要で、修正は1回**
- **2周目は禁止。** 回すほど良くなるわけではなく、迷走が始まる
- 「確認しました」は成果物として認めない。**材料IDと具体的な変更がセットで書けなければ、確認していないのと同じ**
- 該当項目が無いのは正常。無理に適用した結果が最も悪い
