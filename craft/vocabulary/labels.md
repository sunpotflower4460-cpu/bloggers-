# labels.md

ボタンラベルと操作名の語彙。

- 動詞は能動形にする。何が起きるかをそのまま書く（例: 「保存する」であって「保存」ではない）
- 同じ操作は全画面で同じ語を使う（「公開する」を選んだら、完了トーストも「公開しました」で揃える）
- 汎用CTA（「はじめる」「送信」「OK」）は使わない。以下の対応表から選ぶか、同じ考え方で操作固有の語を作る

## 対応表

| 汎用語 | 代わりに（操作に応じて） |
|---|---|
| はじめる | 記録をはじめる / 使ってみる / 最初の◯◯を作る |
| 送信 | 送る / 投稿する / 公開する / 申請する |
| OK | わかった / 続ける / 閉じる |
| 保存 | 保存する / この内容で保存する |
| 削除 | 削除する / 完全に削除する |
| 編集 | 編集する / 内容を変更する |
| 追加 | 追加する / ◯◯を追加する |
| キャンセル | やめる / このまま戻る |
| 完了 | 完了する / 終わらせる |
| 次へ | 次に進む / ◯◯へ進む |
| 戻る | 前の画面に戻る / やり直す |
| 更新 | 更新する / 最新の情報にする |
| 検索 | 探す / ◯◯を探す |
| 設定 | 設定を開く / ◯◯を変更する |
| ログイン | はじめる（初回）/ 続ける（復帰） |
| 共有 | 共有する / ◯◯に送る |
| ダウンロード | 保存する / 端末に保存する |
| 再試行 | もう一度試す / やり直す |
| 閉じる | 閉じる / このまま終える |
| もっと見る | すべて見る / 続きを見る |
