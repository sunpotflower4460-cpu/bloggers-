# SOUL.md

## 一文で言うと

複数ブログを1つの統合HPからAIが継続的に観測・判断・制作・公開・学習しながら育てるAI編集部OS。

## これは何ではないか

- 単なる記事量産ツールではない
- 複数CMSへの一括投稿だけを行うツールではない
- 人間がAIの行動理由を追えないブラックボックスではない

## 消したら別物になる要素（不変条項）

- 複数ブログごとに独立した目的・読者・文体・学習を持つ Blog Brain
- 観測→判断→制作→公開→計測→学習の自律ループ
- 全ブログを横断して優先順位と資源配分を考える Portfolio Brain

## 増えたら死ぬもの（禁止事項）

- 読者価値や品質を無視した記事数KPI
- ブログ間で文体・知識・方針を無制限に混ぜる共有
- 人間が停止・承認・監査できない不可逆な自動操作

## 使い終わった直後、ユーザーが漏らす一言

- ブログを一つずつ見に行かなくても、AI編集部が全部育ててくれている。
