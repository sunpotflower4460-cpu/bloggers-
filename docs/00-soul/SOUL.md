# SOUL.md

## 一文で言うと

初期設定だけで複数のAI編集部がそれぞれのブログを学習しながら育て続け、その成長をひとつの庭のように見渡せる統合HP。

## これは何ではないか

- 同じ記事を複数媒体へ機械的にコピペするだけの一括投稿ツール
- 記事本数だけを増やすSEOスパム生成器
- 毎回人間が細かく指示しないと止まるチャットUI

## 消したら別物になる要素（不変条項）

- ブログごとに独立したテーマ・人格・学習履歴を持つ
- 情報収集→制作→公開→実反応→改善が閉じた循環になる
- 全ブログを一括確認・停止・追加できる統合ダッシュボードがある

## 増えたら死ぬもの（禁止事項）

- 必要以上の手動確認
- 資格情報の平文保存
- 根拠のない事実断定や他サイト文章の大量転載

## 使い終わった直後、ユーザーが漏らす一言

「気づいたら、それぞれ勝手にちゃんと育ってる。」
