## 自由領域の三段階

| 段階 | 対象 | 扱い |
|---|---|---|
| 実行 | 自由領域内。やった上で報告する | 承認不要 |
| 試作 | 境界上。両案を残す（コメントアウトか別ブランチ） | 報告して判断を仰ぐ |
| 提案 | 領域外。BACKLOGへ。実装しない | 承認後のみ |

**以下は承認不要。むしろ積極的に判断すること。**
同一画面内の要素の配置・順序 / 余白の配分（グリッド内）/ 階層の付け方 / 状態遷移の見せ方 / 文言の言い回し（`craft/vocabulary/` の範囲内）/ 既存トークンの組み合わせ方

**以下は承認が必要（戻しにくいため）:**
入口の増減 / トークンの値そのもの / 画面間の遷移構造
