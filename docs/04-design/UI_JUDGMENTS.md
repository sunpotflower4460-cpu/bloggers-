# UI_JUDGMENTS.md

## 方向性

「AI管理画面」ではなく、複数の小さな編集部が育っている庭を眺める感覚にする。

- 黒背景・ネオン・過剰なAI感は避ける
- 数値は重要だが、最上位には「各ブログが元気に動いているか」を置く
- ブログカードは媒体ロゴよりブログ名・テーマ・成長状態を主役にする
- 自動運転は怖く見せず、停止・レビュー運用へ即座に切り替えられる設計にする
- 入口はダッシュボード、初期設定、手動実行の3系統に限定する

## 画面優先順位

1. 今日どのブログが動いたか
2. 何を公開したか
3. 実反応が上向きか下向きか
4. エラーや停止がないか
5. 詳細な技術ログ
