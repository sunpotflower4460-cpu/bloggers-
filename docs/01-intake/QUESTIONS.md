# QUESTIONS.md

## A. ゼロから作る場合（10問）

質問は上から順に聞く。1メッセージあたり質問は最大3問。質問には必ず選択肢（A/B/C + 自由記述）を添える。

1. 一文で言うと何ですか
   - 例: A) 記録用 B) 共有用 C) 学習用 / 自由記述
2. これは「何ではない」ですか（3つ）
   - 例: A) SNSではない B) ゲームではない C) 業務ツールではない / 自由記述
3. 使い終わった直後の一言は
   - 例: A)「スッキリした」 B)「安心した」 C)「早かった」 / 自由記述
4. 生活のどこで使いますか（時間帯・場面）
   - 例: A) 通勤中 B) 就寝前 C) 作業の合間 / 自由記述
5. 最初の画面で「唯一できること」は何ですか
   - 例: A) 記録する B) 確認する C) 選ぶ / 自由記述
6. 成功の定義は（数字でなくてよい）
   - 例: A) 続けられている B) 迷わない C) 誰かに勧めたくなる / 自由記述
7. 触り心地の形容詞3つ / 避けたい形容詞3つ
   - 例: A) 静か・軽い・正直 B) 賑やか・速い・親しみやすい / 自由記述
8. 消したら別物になる要素は
   - 例: A) 記録の即時性 B) 一人称視点 C) オフライン動作 / 自由記述
9. 増えたら死ぬものは
   - 例: A) 通知 B) 設定項目 C) 装飾 / 自由記述
10. 技術的な確定事項（プラットフォーム・配布形態・オフライン可否）
    - 例: A) Web / ストア配布 / オフライン可 B) Web / URL配布 / 常時接続 / 自由記述
